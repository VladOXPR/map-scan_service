Product Context

This application powers a battery-sharing network.

Users locate nearby battery stations on a map.

A user walks to a station, rents a battery, and later returns it to any station in the network.

The primary goal of the application is helping a user find and rent a battery in under 30 seconds.

Every design decision should optimize for speed, clarity, and reducing friction.

The map is the core of the experience and should always feel fast and responsive.

The application should be architected so that future features like battery rental, QR scanning, payment, account management, rental history, and push notifications can be added without major refactoring.
